Sheets

Load dummy data generates dummy data from the staffing snapshot in the discipline sheet and replaces the prototype sheet's contents with it. Set up live sheets adds the tabs, header rows and imports the live sheets need. It never removes or overwrites answers. Set up IC form sets the self-assessment form's questions to the current top areas, keeping existing questions so their answers stay in the same columns. All need edit access.

Top areas

Every area of expertise, including the ones teams add in the survey, grouped into exactly 10 buckets. The IC form asks about the buckets, and supply is counted per bucket. The buckets tab in the discipline sheet is the source of truth: rename a bucket there by hand if you like. To regroup, Ask Gemini copies a prompt listing every area and opens Gemini in a new tab: paste it there, copy Gemini's answer, paste it below and preview what would change. Nothing is written until you apply it.
